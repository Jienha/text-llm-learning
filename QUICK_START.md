# Quick Start Guide 🚀

Welcome to your NLP & LLM learning journey! This guide will get you up and running in minutes.

## 🎯 What You'll Learn

This comprehensive path takes you from NLP basics to advanced LLM concepts:

- **Phase 1**: Text preprocessing, sentiment analysis, text classification
- **Phase 2**: Neural networks, word embeddings, attention mechanisms  
- **Phase 3**: Transformer models (BERT, GPT, T5)
- **Phase 4**: Model fine-tuning and deployment

## ⚡ Get Started in 5 Minutes

### 1. Setup Your Environment
```bash
# Activate your virtual environment
# On Windows:
venv\Scripts\activate
# On Mac/Linux:
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Download NLTK data
python -c "import nltk; nltk.download('all')"
```

### 2. Start Learning
```bash
# Launch Jupyter
jupyter notebook

# Open the first notebook:
# notebooks/01_text_preprocessing_basics.ipynb
```

### 3. Your First Exercise
Open `notebooks/01_text_preprocessing_basics.ipynb` and run the cells. You'll learn:
- How to clean and normalize text
- Tokenization techniques
- Removing stop words
- Stemming and lemmatization
- Building a complete preprocessing pipeline
